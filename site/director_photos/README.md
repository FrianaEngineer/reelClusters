# Director Photos

This folder contains one profile photograph for each of the 60 directors shown
in the supplied cluster screenshots.

- Files use lowercase `snake_case` director names.
- `contact_sheet.jpg` provides a labeled overview of all photographs.
- `manifest.csv` maps every director and filename to the corresponding TMDB
  person ID, profile gallery, and original image URL.

The photographs were retrieved from TMDB profile galleries on July 30, 2026.
Before publishing the photographs, review the applicable image rights and TMDB
attribution requirements.
